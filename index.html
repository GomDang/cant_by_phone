Configuration

측정 설정

유효 측정 간격과 센서 축·부호는 실제 장착 상태에서 확인해야 합니다.

초기값 1,435 mm. 명목 궤간과 실제 수평계 접촉점 사이의 거리가 다를 수 있습니다.

값을 더 오래 평균해 순간적인 흔들림을 줄입니다. 반응이 느려지는 대신 실제 기울기 변화도 늦게 표시됩니다.

센서의 순간 흔들림보다 장시간 평균값의 변동을 기준으로 기록 가능 여부를 판단합니다.

축은 미리 정답으로 지정하지 않습니다. USB-C 포트 방향이 설계서의 장착 기준과 일치하는 상태에서 스마트폰 쪽 레일을 실제로 올려 +값이 나오는지 시험하세요.
